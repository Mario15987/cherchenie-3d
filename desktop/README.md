# «Черчение 3D» для Windows (PySide6)

Нативная версия: 2D-эскиз и чертёж (`QGraphicsView`), 3D (pyqtgraph + OpenGL, геометрия manifold3d),
ИИ-помощник (Anthropic Claude через SDK `anthropic`; OpenAI-совместимые, Gemini, OpenRouter, Groq, свой URL — через HTTP).

## Запуск из исходников

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

## Что умеет

- **Эскиз** — отрезок, прямоугольник, окружность, дуга, осевая; типы линий ГОСТ 2.303 (основная, тонкая, штриховая,
  штрихпунктирная, с двумя точками, волнистая). Точный ввод в панели «Параметры»: координаты, длина и угол,
  радиус или диаметр. Привязки с маркерами: конец, середина, центр, пересечение, перпендикуляр, касательная, сетка.
- **Редактирование** — усечь, удлинить, фаска (два катета или катет и угол), скругление, эквидистанта (кривая или
  весь контур), симметрия, массивы по сетке и по окружности, замыкание разрывов.
- **Оформление** — размеры: горизонтальный, вертикальный, параллельный, ⌀, R, угловой; выноска с полкой;
  шероховатость Ra/Rz; штриховка (металл, неметалл, бетон, стекло) с шагом и углом, отверстия в контуре учитываются.
  Двойной щелчок по размеру — допуск (±0,1, +0,2/-0,1, H7, H7/g6 — поле проверяется по ГОСТ 25346).
- **Лист** — форматы A4–A1, книжный и альбомный, рамка и основная надпись ГОСТ 2.104 форма 1; двойной щелчок
  по графе штампа открывает её правку.
- **3D** — выдавливание (объединение, вычитание, пересечение; вложенные контуры — отверстия), вырез, вращение вокруг
  осевой, оболочка, скругление и фаска рёбер. «Чертёж по модели» строит виды спереди, сверху и слева
  с невидимыми линиями и габаритными размерами.
- **Прямое редактирование в 3D (как в КОМПАС-3D)** — щелчок по верхней грани выдавливания или по дну выреза
  подсвечивает грань, ставит стрелку вдоль нормали и плашку с размером («H: 25.0 мм»). Стрелку тянут мышью: луч из-под
  курсора даёт точку на оси грани, шаг 1 мм, с Shift — 0,1 мм; модель показывает полупрозрачный фантом будущей формы,
  а поле «Высота выдавливания H» / «Глубина выреза» в панели «Параметры» меняется вместе с ней. Отпустили — число уходит
  в операцию (Ctrl+Z), тело и виды «Чертежа по модели» перестраиваются; Esc или ПКМ — отмена. Двойной щелчок по плашке,
  по грани или по операции в дереве — быстрый ввод точного значения. Если за операцией идут скругление, фаска или
  оболочка, фантом — тело самой операции (полный пересчёт — после отпускания). Боковые грани задаются эскизом.
- **Динамический ввод у курсора** — при черчении рядом с перекрестием (+16, +16 px) бейдж с размерами на лету:
  `L: 125.40 мм | ∠: 30.0°` с размерной линией и дугой угла на холсте, `Ø: 60.00 мм (R: 30.00 мм)`,
  `Ш: 100.00 мм × В: 50.00 мм`; в режиме выбора — длина, угол или Ø и координаты под курсором; при перетаскивании
  точки — новый размер; в 3D при протяжке стрелки — `Глубина H: … мм`. Начните печатать цифры — поле ввода появится
  у курсора: Tab переключает L ↔ ∠ или Ш ↔ В, Enter фиксирует, Esc возвращает к мыши.
- **Рамка выделения как в КОМПАС-3D** — с Ctrl инвертирует выделение попавших объектов, с Shift добавляет их.
- **Аксонометрия ГОСТ 2.317** — в 3D пресеты «Изометрия ГОСТ» (ортогональная, возвышение 35,264°, азимут 45°,
  оси под 120°) и «Диметрия ГОСТ»; режимы «Тонированный с рёбрами», «Каркас» и «Технический» (видимые рёбра —
  сплошная толстая, невидимые — штриховая); «Размеры 3D» — габариты L, W, H и диаметры Ø прямо на модели.
  «Изометрия на лист» строит приведённую изометрию модели (окружности — эллипсы 1,22d × 0,71d, невидимые линии
  убраны) в правом верхнем углу листа; «Виды + изометрия» — спереди, сверху, слева и изометрия вместе; обе
  перестраиваются за моделью. «Изометр. сетка» (F7) — сетка 30° / 90° / 150°, отрезки идут вдоль её осей.
- **Создать** (Ctrl+N, при запуске) — «Документ» / «Документ по шаблону»: Деталь, Сборка, Чертёж, Фрагмент,
  Текстовый документ, Спецификация; специальные — Металлоконструкции, Кабельный канал, Вентиляция, Трубопровод,
  Листовая деталь, СПДС. Чертёж, Технологическая сборка (формат, форма надписи, шифр, сетка, раздел каталога);
  внизу «Знаете ли вы, что:» с кнопками `<<` `>>`.
- **ЕСКД / ГОСТ** (меню, вкладка ленты, панель справа, F1) — справочник 2.001…2.755 с поиском по номеру и названию,
  таблицами и кнопками «сделать в программе». Основная надпись ГОСТ 2.104: форма 1 (185×55), 2 (185×40), 2а (185×15);
  форматы А0–А4 и кратные (ГОСТ 2.301); масштаб листа из ряда ГОСТ 2.302 — изображение пересчитывается, размерные
  числа остаются натуральными; девять типов линий и толщина s 0,5…1,4 мм (ГОСТ 2.303); шрифт тип А / Б, с наклоном
  или прямой (ГОСТ 2.304); штриховки металла, неметалла, дерева, стекла, бетона, жидкости, грунта (ГОСТ 2.306);
  технические требования над штампом колонкой 185 мм (ГОСТ 2.316); спецификация ГОСТ 2.106 — разделы собираются из
  дерева построения и элементов библиотеки, таблица на А4 (если на листе уже чертёж — отдельным листом рядом);
  пояснительная записка ГОСТ 2.105; шифр схемы ГОСТ 2.701 (Э3, Г1…) в основную надпись. «Нормоконтроль» (F9) —
  графы основной надписи, масштаб, линии за рамкой и на штампе, толщины линий, высоты шрифта, наличие размеров.
- **3D-навигация** — гизмо в правом верхнем углу: шары осей ±X/±Y/±Z и полупрозрачный куб, повёрнутые как сцена.
  Щелчок по шару или грани плавно открывает вид (спереди, сзади, слева, справа, сверху, снизу), перетаскивание вращает
  камеру. Рядом кнопки «Перспектива / ортогональная» (клавиша 5) и «Центрировать модель» (Home).
- **Формат полотна** (лента «Чертёж», меню «Вид», окно «Новый документ») — бесконечное полотно (фрагмент) или лист
  А4/А3 (а также А2/А1) с рамкой и штампом. Переключение не трогает начерченное; на фрагменте рамка скрыта, но данные
  штампа хранятся. Последний выбор — в `config.json`. При экспорте листа в DXF/SVG можно выгрузить его без рамки.
- **Параметрическое редактирование (как в КОМПАС-3D)** — панель «Параметры» выделенного объекта, точность 0,01 мм:
  у отрезка длина L, угол α, начало и конец (новая длина откладывается от начала по прежнему углу, новый угол
  поворачивает отрезок вокруг начала); у окружности Ø и R, связанные жёстко, центр и галочка «Осевые линии»;
  у дуги R, Ø и углы; у прямоугольника (выделяется целиком) ширина W, высота H и угол. Двойной щелчок по отрезку,
  окружности или прямоугольнику открывает быстрый ввод у курсора: печатаете число, Enter.
  Размер, поставленный на концы отрезка, углы прямоугольника или на окружность, ассоциативный: следует за геометрией,
  а двойной щелчок по его цифре и новое значение меняют саму геометрию (Ø40 → Ø65). Характерные точки: у отрезка
  концы и середина, у окружности центр и 4 точки обода, у прямоугольника углы — тянутся мышью, размер виден в
  строке состояния. Каждая правка — в Ctrl+Z/Ctrl+Y; правка эскиза операции перестраивает 3D, а виды «Чертежа по
  модели» на листе перестраиваются вслед за моделью.
- **Выделение как в КОМПАС-3D** — щелчок выбирает один объект; Shift или Ctrl+щелчок добавляет или снимает;
  Ctrl+A — всё начерченное, Esc — снять. Рамка с пустого места: слева направо (синяя, сплошная) берёт только
  целиком вложенное, справа налево (зелёная, штриховая) — и пересечённое; с Shift/Ctrl прибавляет. Прямоугольник
  и элемент библиотеки — один объект. Выбранное тянется мышью целиком; Ctrl+C / Ctrl+V — копия у курсора.
  Для нескольких объектов панель «Параметры» показывает «Выбрано объектов: N», общую длину отрезков или диаметр
  окружностей, стиль линии, сдвиг ΔX/ΔY, поворот, отражение и действия над группой.
- **ПКМ-редактор** — правая кнопка по объекту выделяет его и открывает панель у курсора: у отрезка L, α, стиль,
  «Поставить размер», «Разделить пополам», «Перпендикуляр из середины», «Переместить / повернуть», «Дублировать»;
  у окружности Ø/R, оси, стиль, размер Ø; у прямоугольника W/H и «Разбить на отдельные линии»; у элемента
  библиотеки маркировка, поворот ±90° вокруг точки вставки, масштаб и «Разрушить»; у размера значение, допуск,
  свой текст и «Разрушить на примитивы». При выделенной группе — «Редактор группы (N шт.)»: общая L или Ø, стиль,
  сдвиг, поворот, выравнивание, замыкание контура, «Выдавить в 3D», «Мои элементы», копирование, удаление.
  Во время черчения ПКМ завершает команду. Поля применяются сразу, каждая правка отменяется Ctrl+Z.
- **Библиотека ГОСТ / СПДС / ЕСКД** (меню «Библиотека», вкладка ленты «Библиотека», панель справа, Ctrl+B) —
  поиск по названию и ключевым словам, векторные значки и превью.
  - *Шаблоны листов*: однолинейная схема с таблицей нагрузок и шиной (А3/А4), трасса ВЛ с ведомостью опор (А3),
    график ТО со спецификацией оборудования (А4), архитектурный план с экспликацией (А3, М1:50), узел и схема
    фундамента (А4), деталь в трёх проекциях (А4/А3, виды строятся по модели), спецификация по ГОСТ 2.106 (А4).
  - *Элементы и УГО* (50): автоматы 1P/3P, разъединитель, УЗО, предохранитель, трансформаторы, счётчик, двигатель,
    заземление, розетки, выключатель, светильник, муфта; опоры ВЛ (знак на плане и вид), траверса, изоляторы, зажимы СИП,
    контур заземления; оси с марками, стены, перегородки, двери, окна, ворота, лестница, колонна, отметка, вентшахта,
    сантехника (М1:100); болт, гайка, шайба (спереди и сверху), профильная труба, швеллер, уголок, двутавр, подшипник,
    фланец, обозначение сварного шва (М1:1).
  - *Вставка*: элемент висит на курсоре с привязками; R или Пробел — поворот на 90°, Ctrl+колесо или поле
    «Масштаб» — размер, щелчок — поставить. Маркировка (QF1, ОП-12, А) привязана к элементу и после вставки
    увеличивается сама. Щелчок выделяет элемент целиком, двойной щелчок меняет маркировку, в дереве элемент — один узел.
  - *Мои элементы*: «Сохранить выделенное в библиотеку» пишет узел в `user_library.json` рядом с программой.
  - *ИИ-помощник* знает каталог с выводами элементов: команды `insert_library_block`, `load_template`, `add_wall`, `add_text`.
- **Вложения в чате ИИ** — кнопка «📎 Прикрепить», перетаскивание файлов в панель чата или Ctrl+V со скриншотом в поле
  запроса: фото и сканы (`.png .jpg .jpeg .webp .bmp`), Word (`.docx`), текст (`.txt .csv .json`). Над полем — лента
  вложений с миниатюрой или значком DOCX и кнопкой «×». Фото поворачивается по EXIF, сжимается до 1600 px по длинной
  стороне и уходит в Base64 в формате провайдера: `image` (Anthropic), `image_url` (OpenAI, OpenRouter, Groq, свой
  сервер), `inlineData` (Gemini). Вместе с картинкой — сводка локального анализа (numpy + Pillow): пропорции объекта,
  окружности и массивы отверстий, дуги, длинные прямые, симметрия. Word разбирается без внешних программ (zipfile +
  ElementTree): текст, заголовки, списки, таблицы (в Markdown), надписи; рисунки из `word/media` прикрепляются картинками.
  Быстрые сценарии: «Оцифровать фото чертежа / эскиза», «Начертить деталь по фото» (2D с управляющими размерами и 3D),
  «Построить чертеж / схему по ТЗ из Word». Набранный в поле текст добавляется к сценарию; если нужного вложения нет,
  открывается выбор файла. Если запрос не прошёл, вложения возвращаются в поле. На листе А4/А3 `extrude` берёт копию
  контуров листа (`region` — только внутри прямоугольника).
- **Дерево и история** — Ctrl+Z/Ctrl+Y на любую операцию; двойной щелчок по операции — её параметры, по эскизу
  операции — правка эскиза с перестройкой модели после каждого изменения.

Ограничения ядра: скругление и фаска 3D обрабатывают **все** выпуклые рёбра тела разом (морфологическое
открытие в manifold3d), а не выбранное ребро; выбранные вертикальные рёбра скругляйте в эскизе до выдавливания.
На сложных телах (фаска → оболочка → скругление) пересчёт занимает до 15 с; готовые шаги дерева кэшируются.

## Тесты

```
.venv\Scripts\python -m unittest tests.test_core tests.test_ui tests.test_kompas_parity tests.test_selection tests.test_attachments tests.test_direct3d tests.test_eskd
```

`test_kompas_parity` — сценарии КОМПАС-3D: отрезок 30°/100 мм → 250 мм с Undo/Redo, окружность Ø40 → Ø85,
управляющие размеры и характерные точки, пластина с отверстием на А4 → выдавливание → правка эскиза → 3D и виды,
регрессия темы, зума, куба ориентации и библиотеки.
`test_selection` — Shift/Ctrl-выделение, окно и секущая рамка, ПКМ-редактор отрезка, окружности, группы,
разбиение прямоугольника, элемента библиотеки и размера.

`test_eskd` — бейдж и ввод у курсора, изометрия ГОСТ 2.317 (оси, эллипс, вид на листе), рамка с Ctrl, формы
основной надписи, масштабы, линии, штриховки, ТТ, спецификация, записка, шифр схемы, справочник, нормоконтроль,
стартовый экран.

`test_direct3d` — ручки граней и луч в сцену, пересчёт вершин меша при новой высоте выдавливания и глубине выреза
через программный вызов манипулятора, протяжка стрелки мышью (Shift, Esc, ПКМ), фантом, поле панели, виды на листе,
двойной щелчок по размеру и по операции в дереве.

`test_attachments` — Word от python-docx и от встроенного писателя (текст, таблица, рисунок, надписи, объединённые
ячейки), фото с EXIF, сжатие и Base64, анализ чертежа и фото детали, форматы Vision-запроса всех провайдеров, кнопка
«📎», перетаскивание, Ctrl+V, «×» и три сценария с построением по ответу (сервер подменён, сеть не нужна).

`test_core` — геометрия, правки, размеры, штамп, тела, виды, история, экспорт. `test_ui` открывает окно без показа
(диалоги отвечают значениями по умолчанию), рисует мышью каждым инструментом и нажимает каждую кнопку ленты:
кнопка, после которой ничего не изменилось, валит тест.

## Сборка

```
.venv\Scripts\pyinstaller --noconfirm KompasCAD.spec
```

Результат: `dist\KompasCAD\KompasCAD.exe` и его копия под новым именем `dist\KompasCAD\Черчение 3D.exe` (оба запускают
одну программу с общими `_internal` и `config.json`; папка целиком переносится на другой компьютер, Python не нужен).
Проверка сборки: `KompasCAD.exe --selftest` пишет `selftest.txt` рядом с программой.

## Иконка

`assets/icon_source.webp` — исходник. `tools/make_icon.py` делает углы за скруглённой рамкой прозрачными
и пишет `assets/icon.png` и `assets/icon.ico` (16–256 px); нужен Pillow: `.venv\Scripts\python -m pip install pillow`.
Иконка вшита в `.exe` (параметр `icon` в `KompasCAD.spec`) и ставится окну и приложению из `assets` (через `sys._MEIPASS`).

## Файлы

- `*.k3d` — проект (JSON): примитивы эскиза, операции с копией профиля, рамка со штампом.
- `config.json` рядом с `.exe` — настройки ИИ. Для работы с фото в настройках нужна модель с поддержкой изображений
  (Vision) — памятка об этом есть в «Справка → О программе» и под полем «Модель» в «Настройках ИИ». **API-ключ хранится открытым текстом**, в git файл не попадает.
- `user_library.json` рядом с `.exe` — «Мои элементы» библиотеки (в git не попадает).

## Оформление

«Вид → Оформление…» (Ctrl+Shift+T) или кнопка 🎨 справа на ленте: светлая и тёмная классические темы,
8 светлых пастельных и 14 тёмных тем, «Своя тема» из трёх цветов (фон, второй цвет градиента, акцент).
Тема меняет панели, лист чертежа и 3D-поле; галочка «Оставить классический фон чертежа» красит только панели.
Выбор хранится в `config.json` рядом с программой.

## Горячие клавиши

В эскизе: L — отрезок, R — прямоугольник, C — окружность, A — дуга, D — размер, T — усечь, S — выбор, Esc — отмена,
Delete — удалить, F — показать всё, колесо — масштаб, средняя кнопка — сдвиг, ПКМ — закончить цепочку.
Ctrl+Z / Ctrl+Y — отмена и повтор (в том числе команд ИИ), Ctrl+I — ИИ-помощник, Ctrl+Enter — отправить.
