# Черчение 3D

Лёгкая САПР для Windows: 2D-эскиз, чертёж по ЕСКД/ГОСТ, 3D-моделирование и ИИ-помощник, который чертит по словам,
по фото чертежа или детали и по техническому заданию в Word.

## Скачать

Готовая программа — в разделе [Releases](../../releases): скачайте `Cherchenie-3D-windows-x64.zip`, распакуйте
и запустите `Черчение 3D.exe`. Установка и Python не нужны, папку можно переносить целиком.

## Возможности

- **Эскиз и чертёж** — отрезки, прямоугольники, окружности, дуги, осевые; типы линий ГОСТ 2.303; привязки;
  усечение, фаски, скругления, эквидистанта, массивы. Размеры (линейные, Ø, R, угловые) с допусками, выноски,
  шероховатость, штриховка. Листы А4–А1 с рамкой и основной надписью ГОСТ 2.104.
- **Параметрическое редактирование** — точный ввод длины, угла, диаметра в панели «Параметры» и по двойному щелчку,
  управляющие размеры (новое число меняет геометрию), характерные точки, Ctrl+Z / Ctrl+Y на любую правку.
- **Выделение и ПКМ-редактор** — Shift/Ctrl-выделение, рамка «окно» и «секущая», групповые правки, контекстная
  панель у курсора для отрезка, окружности, прямоугольника, элемента библиотеки, размера и группы.
- **3D** — выдавливание, вырез, вращение, оболочка, скругление и фаска рёбер; «Чертёж по модели» строит три вида
  с невидимыми линиями и размерами и перестраивает их вслед за моделью.
- **Прямое редактирование в 3D** — щелчок по грани выдавливания или по дну выреза ставит стрелку с размером
  («H: 25.0 мм»); стрелку тянут мышью, фантом показывает будущую форму, поле в панели меняется на лету;
  двойной щелчок — точное значение.
- **Библиотека ГОСТ / СПДС / ЕСКД** — 50 элементов и УГО (электрика, ВЛ, строительство, машиностроение) и 9 шаблонов
  листов: однолинейная схема, трасса ВЛ, план, спецификация, деталь в трёх проекциях. Свои элементы — «Мои элементы».
- **ИИ-помощник** — Anthropic Claude, OpenAI-совместимые серверы, Google Gemini, OpenRouter, Groq. Отвечает командами,
  которые сразу выполняются на холсте. Можно приложить фото чертежа или эскиза, фото реальной детали, скриншот
  (Ctrl+V), документ Word (`.docx` — текст, таблицы, рисунки) или `.txt / .csv / .json`. Программа сама сжимает фото,
  считает по нему габарит, окружности и массивы отверстий и отправляет это ИИ вместе с картинкой.
- **Оформление** — светлые и тёмные темы, своя тема из трёх цветов.
- **Экспорт** — DXF, SVG, STL, OBJ.

> 💡 Чтобы ИИ «видел» приложенные фото, в «Настройках ИИ» нужна модель с поддержкой изображений (Vision).

API-ключ ИИ хранится в `config.json` рядом с программой, открытым текстом; в репозиторий и релизы он не попадает.

## Из исходников

```
cd desktop
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

Тесты и сборка `.exe` — в [desktop/README.md](desktop/README.md).

## Состав репозитория

- `desktop/` — программа для Windows: Python, PySide6 (Qt), pyqtgraph + OpenGL, геометрическое ядро manifold3d.
- `app/` — ранний браузерный прототип (React, Three.js, Vite).

## Сторонние компоненты

Qt for Python (LGPLv3), manifold3d (Apache-2.0), pyqtgraph (MIT), numpy (BSD), Pillow (MIT-CMU), Anthropic SDK (MIT).
«КОМПАС-3D» — товарный знак АСКОН; проект с ним не связан, упоминания — только для сравнения приёмов работы.
